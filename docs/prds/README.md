# PRD issue packs

Each product requirement document has its own folder under `docs/prds/<slug>/`.

- **`prd.md`** — product requirements for that feature.
- **`README.md`** — index and links to issues.
- **`issues/`** — vertical-slice work items (tracer bullets), ready for AFK implementation.

Issue files use YAML front matter (`title`, `type`, `blocked_by`) and the shared body sections: What to build, Acceptance criteria, Blocked by.
